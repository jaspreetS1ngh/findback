# FindBack

FindBack is a team-developed lost-and-found application built with Java, Spring Boot, PostgreSQL, Docker, and JUnit. The application helps connect lost-item reports with potential matches.

The completed application was containerized using Docker and deployed to Render for a project demonstration. The hosted demo is no longer active.

## My Contributions

- Reviewed teammates' code and suggested improvements to implementation quality.
- Participated in two-week Agile sprints, weekly progress meetings, and development discussions on Discord.
- Used ChatGPT to brainstorm potential edge cases when planning application tests.

## Testing

The project uses JUnit for automated testing. Run the Maven test suite with `./mvnw test` from the project root.
